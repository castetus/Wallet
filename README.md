# Wallet

Консольное приложение для учёта личных финансов на Java 21.

Приложение позволяет нескольким пользователям вести раздельный учёт доходов и расходов, создавать категории, устанавливать бюджеты и просматривать финансовые отчёты.

## Требования и запуск

- Java 21
- Maven

Запустите класс `wallet.Main` из IDE. После запуска приложение принимает команды в консоли.

Команды вводятся в одну строку. Аргументы разделяются пробелами. Названия, содержащие пробелы, нужно заключать в двойные кавычки: `"Домашние животные"`.

## Команды

### Пользователи

| Команда | Описание | Пример |
| --- | --- | --- |
| `register <username> <password>` | Зарегистрировать пользователя и создать его кошелёк | `register alice 123` |
| `login <username> <password>` | Войти в учётную запись | `login alice 123` |
| `logout` | Выйти из учётной записи | `logout` |
| `exit` | Завершить приложение | `exit` |

### Категории

| Команда | Описание | Пример |
| --- | --- | --- |
| `category add <type> <name>` | Создать категорию доходов или расходов | `category add expense "Food"` |
| `category list` | Показать все категории пользователя с их типами | `category list` |

Допустимые значения `<type>`: `income` (доход) и `expense` (расход). Категории с одинаковыми именами допустимы, если их типы различаются. В рамках одного типа имя категории должно быть уникальным.

### Доходы и расходы

| Команда | Описание | Пример |
| --- | --- | --- |
| `income <category> <amount>` | Добавить доход в указанную категорию | `income "Salary" 100000` |
| `expense <category> <amount>` | Добавить расход в указанную категорию | `expense "Food" 500` |
| `transactions` | Показать историю доходов и расходов | `transactions` |

Категория должна существовать и соответствовать типу операции. Сумма должна быть положительной. Внутри приложения денежные значения хранятся целыми числами в минимальных денежных единицах; формат пользовательского ввода и валюта определяются при реализации.

### Бюджеты

| Команда | Описание | Пример |
| --- | --- | --- |
| `budget set <category> <amount>` | Установить или изменить лимит расходов для категории | `budget set "Food" 15000` |
| `budget list` | Показать установленные бюджеты и расходы по ним | `budget list` |

Бюджет устанавливается только для категории типа `expense`. При превышении лимита приложение сообщает о перерасходе.

### Баланс и отчёты

| Команда | Описание | Пример |
| --- | --- | --- |
| `balance` | Показать текущий баланс кошелька | `balance` |
| `report` | Показать сводный финансовый отчёт | `report` |
| `report categories` | Показать суммы доходов и расходов по категориям | `report categories` |

Баланс рассчитывается как сумма доходов минус сумма расходов. Сводный отчёт включает общий объём доходов и расходов, баланс, сведения о бюджетах и предупреждения о превышении лимитов или отрицательном денежном потоке.

### Переводы между пользователями

| Команда | Описание | Пример |
| --- | --- | --- |
| `transfer <username> <amount>` | Перевести средства другому зарегистрированному пользователю | `transfer bob 2000` |

Перевод уменьшает баланс отправителя и увеличивает баланс получателя. Операция должна учитываться у обоих пользователей.

## Пример работы

```text
> register alice 123
> login alice 123
> category add income "Salary"
> category add expense "Food"
> income "Salary" 100000
> expense "Food" 500
> budget set "Food" 15000
> category list
> transactions
> balance
> budget list
> report
> logout
> exit
```

## Правила работы

- Каждый пользователь работает только со своим кошельком.
- Для операций с категориями, транзакциями, бюджетами и отчётами необходимо войти в учётную запись.
- Данные пользователей и их кошельков сохраняются в файлы и восстанавливаются при последующих запусках приложения.
- Ошибочные команды, неверные аргументы, отсутствующие категории и другие некорректные операции должны сопровождаться понятным сообщением об ошибке.

## Структура проекта

```text
src/main/java/wallet/
├── Main.java       # создание зависимостей и запуск
├── cli/            # чтение и разбор команд, вывод результатов
├── controller/     # валидация аргументов и вызов сервисов
├── service/        # бизнес-логика
└── model/          # пользователи, кошельки, категории, операции, бюджеты
```
